2. 필요 기능
- 신청하기 기능
- 요약 : 유저가 신청하기 버튼을 통해 양식 샘플을 다운 받고 해당 샘플을 작성해서 업로드하여 중소기업 인재키움 프리미엄을 신청함
- 상세
 - 신청 프로세스  
  - [지금 신청하기] 클릭 > 모달 발생 > 해당 모달에서 샘플을 다운로드 할 수 있고 해당 샘플을 다운로드해서 업로드할 수 있는 기능 제공
  - 해당 모달에서 신청하는 사람의 정보도 수집
  - (모든 정보는 필수 정보로, 입력해야 [신청하기] 버튼 활성화) 수집 필요 정보 : 신청자 회사명, 신청자 이름, 신청자 이메일, 
  - 샘플 업로드 완료하면 "완료되었습니다. 담당자의 연락을 기다려 주세요" 발생
  - 신청한 사람의 메일로 신청 확인 메일 송신
  - 샘플은 현재 프로젝트 폴더 내의 sample.xlsx 파일로 사용

 - 알림 프로세스
  - 이메일
   - 신청이 완료되면 담당자 이메일(ariel@inflab.com, shhwang@inflab.com, hj.kim@inflab.com, leez0602@inflab.com)로 신청 내용에 대한 이메일 발생
   - 이메일 내용은 적당히 작성해 주되 하기 내용은 필수로 포함
    - 첨부파일로 신청자가 업로드한 파일
    - 모달에서 받은 신청자 정보

  - 슬랙 알림
   - 슬랙 채널에 이메일과 같은 내용으로 알림 진행

 - 기타 기능
  - 모달 내 상단에 우선지원대상기업 소속의 근로자 대상으로 '기업 단위'로만 신청 가능함을 다시 한 번 명시
  - 우선지원 대상 기업 확인 방법 소개
    - 전화문의
      - 고용노동부 고객 센터 : 국번없이 1350
      - 근로복지공단 : 1588-0075
  - 우선지원 대상 기업 신청 링크 삽입 : https://www.gov.kr/mw/AA020InfoCappView.do?HighCtgCD=A05007&CappBizCD=14900000031&tp_seq=
